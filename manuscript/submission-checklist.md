# RNAAS submission checklist

- [x] English manuscript source prepared in AASTeX v7 syntax.
- [x] Required abstract is below 150 words (repository count: 116 words).
- [x] One table and no figure.
- [x] Numerical claims cross-checked against the archived reports.
- [x] No discovery or confirmation claim.
- [ ] Add the author's real ORCID only if one exists and is verified.
- [x] Publish the Zenodo record and insert its version DOI in the availability statement.
- [ ] Run the AAS-recommended `texcount` command and retain its output.
- [ ] Compile with the current AASTeX v7 distribution and inspect every page.
- [ ] Confirm title, author spelling, affiliation, email, acknowledgments, and
      contributor consent.
- [ ] Confirm the AAS subject keywords in the submission system.
- [ ] Review the current AAS professional, ethical, and preparation policies.
- [ ] Read and accept the journal's CC BY 4.0 publishing agreement personally.
- [ ] Upload source and bibliography through the author's AAS account.
- [ ] Record the submitted manuscript ID; do not claim acceptance before the
      editor's decision.
